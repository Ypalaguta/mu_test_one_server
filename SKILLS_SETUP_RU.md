# Умения версии 3

Используй README_RU.md в корне нового общего архива. Теперь каждый ранг — отдельная запись (familyId/prev/replaces/stats). Старые groupId/maxLevel/growthStats удалены. Каталог содержит 450 записей. Миграций нет: новый seed рассчитан на новые characters и skills.

После создания новых коллекций: npm run seed:static, затем npm run seed:dev.
Запрос состояния/запись персонажа доступны только доверенному UE-серверу с GAME_SERVER_TOKEN. Изучение, модификаторы и инвентарь проверяются C++ компонентами на UE-сервере.
